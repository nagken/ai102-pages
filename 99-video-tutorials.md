## How to use these videos

1. **First pass - John Savill AI-102 Study Cram**. He refreshes it whenever Microsoft renames or restructures the AI portfolio - make sure you watch the **latest** one (post-2026 Microsoft Foundry rename).
2. **Second pass - AI Show on Microsoft Learn** for any service Savill covered too quickly: Document Intelligence, Speech, Custom Vision, AI Search hybrid + semantic ranker, content safety.
3. **Third pass - Microsoft Reactor sessions on Foundry / Agent Service** for the agentic-AI portion of the exam. This is the highest-churn area; first-party demos are the safest source.
4. Then take the **Practice Assessment** (see that page in the sidebar) before scheduling the real exam.

> Tip: the exam now uses "Microsoft Foundry" and "Foundry Models" in question text - anything from before the 2026 rename will still teach the right *concept* but the *names* will be stale. Always cross-check terminology against this guide and Microsoft Learn.
